# Phase 1 screenshots

This directory contains sanitized visual evidence from the short-lived Phase 1
acceptance run. Machine-readable counts, temporal results, and teardown checks
are recorded in [`../../phase-1-verification.md`](../../phase-1-verification.md).

The AWS images exclude the account banner and assumed-role session. None of the
images contains credentials, IP addresses, or database endpoints. Included
files:

- `airflow-successful-runs.jpg`
- `aws-rds-teardown.jpg`
- `aws-sqs-teardown.jpg`

Screenshots demonstrate the operator-visible state. They do not replace the
automated checks.
